## `whoami`

I’m **Jaramie Morris**, an AI Software Engineering student and hands-on systems builder. I build local-first tools for investigation, learning, and creative computing—usually with a command-center interface and a little phosphor glow.

```txt
primary_lane   = AI systems + defensive security tooling
interface_bias = terminals, maps, dashboards, embedded hardware

operating_rule = make it useful → make it legible → make it memorable
```
